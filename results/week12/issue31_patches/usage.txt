Activate a compatible environment. For a fresh checkout, one setup is:

    python3.11 -m venv .venv
    . .venv/bin/activate
    python -m pip install -r results/week12/issue31_patches/requirements-reproduce.txt
    python -m pip install --no-deps -e external/coralai -e external/coralai/coralai/dependencies/PyTorch-NEAT

wheel index. The complete requirements-used.txt files preserve the original pip
freeze, including historical local paths; do not use those freezes as installers.
